# OnlyIdeas papers

Public cleared paper bundles only. Never add private uploads, original PDFs,
session data, credentials or comments from a private thread. A bundle requires
paper.mmd, metadata.json, source/provenance/license and all referenced figures.
Retain upstream attribution. Translation is a derivative; check permission.
Do not use a default repository license to relicense third-party papers.
App code and workers belong in ../OnlyIdeasApp.
